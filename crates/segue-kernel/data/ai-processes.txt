# Built-in AI process list. The kernel merges this with the signed bundle's
# own list to decide which processes belong to the AI tier. `#` starts a
# comment. A line is one of:
#   name  <exact process name>        e.g. `name claude` (add the .exe form
#                                     separately on Windows if the matcher
#                                     does not strip it)
#   path  <absolute path or prefix/>  e.g. `path /Applications/Claude.app/`
#   bundle <macOS bundle id>          e.g. `bundle com.anthropic.claudefordesktop`
#   cmd  <basename of the script a generic runtime runs>
#                                     for node/python CLIs whose process shows
#                                     up as the runtime itself (node, python,
#                                     Electron): `cmd gemini` matches
#                                     `node .../gemini`. Never use it for
#                                     tools that exec a native binary.
#
# Generic names that would capture everything (node, python3, Electron,
# "Code Helper", chrome, pwsh) are deliberately NOT listed as `name`; only
# vendor-qualified helper names like "Claude Helper (GPU)" are.
# Verified on this Mac 2026-11-17 (`ls /Applications`, `mdls -name
# kMDItemCFBundleIdentifier`, `which`, Info.plist/Frameworks inspection).
# Everything else is marked `# unverified` and comes from vendor docs or
# widely published bundle ids; re-verify before tightening policy on it.

# --- Anthropic: Claude desktop -------------------------------------------
# Electron app. Helper process names verified in Contents/Frameworks/.
name Claude
name Claude Helper
name Claude Helper (GPU)
name Claude Helper (Plugin)
name Claude Helper (Renderer)
bundle com.anthropic.claudefordesktop
path /Applications/Claude.app/
# Windows installs to %LOCALAPPDATA%\Programs\Claude\ (Claude.exe, same
# helper naming). unverified

# --- Anthropic: Claude Code ----------------------------------------------
# Native Bun-compiled binary (verified Mach-O on this Mac), installed to
# ~/.local/bin/claude; the VS Code and JetBrains extensions exec the same
# binary, so `name claude` covers them. The npm install (@anthropic-ai/
# claude-code) runs `node .../cli.js`, hence the cmd line.
name claude
cmd claude
# Windows native build is claude.exe in %USERPROFILE%\.local\bin. unverified

# --- OpenAI: Codex CLI ----------------------------------------------------
# Native Rust binary (verified Mach-O on this Mac, ~/.local/bin/codex). The
# npm wrapper (@openai/codex bin/codex.js) only execs this binary, and the
# IDE extensions bundle their own copy of it, so `name codex` covers the CLI,
# the wrapper's child, and the extensions. cmd codex is kept for the
# short-lived node wrapper process itself.

# codex binary in ~/.local/bin on this Mac.

# Windows native build is codex.exe. unverified
