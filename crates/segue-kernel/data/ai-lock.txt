# Built-in AI destinations. The kernel merges this with the signed bundle's
# ai_domains / ai_cidrs. A line is `suffix <domain>` or `cidr <prefix>`.
# `#` starts a comment. Suffixes match the name and every subdomain.
#
# A suffix is the whole registrable name when that name is the product, or a
# single account-bearing host when the parent is shared (Sentry, S3, Azure).
# Shared front doors are not listed: pinning them would send other apps
# through the AI exit. Sources, retrieval date 2026-11-17, and the CIDR
# decision are in docs/research/ai-destinations.md.

# MCP proxy, downloads, and the claude.ai / claude.com apps. statsig.anthropic.com
# is NXDOMAIN as of the retrieval date; telemetry now goes to api.anthropic.com
# and to shared Datadog hosts, which are not listed.
suffix anthropic.com
suffix claude.ai
suffix claude.com
# Artifact frames, the Claude-in-Chrome bridge, and MCP widgets. Vendor-owned;
# not a shared CDN name.
